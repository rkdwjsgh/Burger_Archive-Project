# 🍔 버거 아카이브

2024년부터 먹어본 버거 기록을 모은 개인 아카이브

## 페이지
- **버거 로드**: 먹은 순서대로 펼쳐진 타임라인 지도
- **버거 조회**: 브랜드·연도·별점 필터와 키워드 검색

같은 기록을 두 가지 방식으로 표현

버거 로드는 시간 순서를 따라가며 보고, 버거 조회는 원하는 기록을 찾아 비교

## 설계하면서 고민한 점

### 점수를 어떻게 보여줄까
- 점수가 2~3점대에 몰려 있어 그대로 색을 입히면 차이가 명확하지 않았음
  → 1점과 4점을 색의 양 끝(빨강·초록)으로 고정해 보정
- 가운데 색을 노랑으로 하면 브랜드 색과 겹쳐 회색으로 변경
- 점수만으로는 맛있었던 메뉴가 드러나지 않아 👍 추천 표시를 추가

### 무엇을 검색으로, 무엇을 필터로 할까
- 별점은 입력보다 고르는 게 자연스러워 구간 필터로,
  추천은 반대로 필터 대신 "추천" 검색어로 찾게 함
- `메뉴명:새우`처럼 범위를 지정하는 키:값 검색을 넣고, 키가 없으면 전체를 찾음
- 자동완성은 메뉴만 보여주고, 누르면 바로 상세 정보가 열림

### UI
카드 텍스트 최소화, 옆 슬라이드 상세 패널, 고정 필터 바 등
보기 편하도록 세부적인 부분을 여러 차례 다듬었음

## 사용 기술
React, Vite, React Flow

## 실행 방법
Node.js(LTS)가 설치되어 있어야 합니다.

```
git clone https://github.com/rkdwjsgh/Burger_Archive-Project.git
cd Burger_Archive-Project
npm install
npm run dev
```

실행 후 터미널에 표시되는 주소(기본 `http://localhost:5173`)로 접속합니다.
